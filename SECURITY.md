# Security policy

The tools are read-only reviewers; they are **not** an isolated execution sandbox, not a comprehensive security scanner and do not make guarantees about third-party artifacts or Kubernetes clusters. Do not submit secrets, customer workloads, production access tokens, untrusted archive bombs or exploit content in public GitHub Issues. For suspected vulnerabilities in the scanner itself, use a private GitHub security advisory if enabled by the repository owner. Keep reproductions synthetic and disclose input limits, unsafe parsers and false negatives transparently.
